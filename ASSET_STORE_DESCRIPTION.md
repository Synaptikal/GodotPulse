# GodotPulse Asset Store Description

## Short Description (250 chars)
Professional in-game performance overlay and diagnostics plugin for Godot 4 .NET projects. Real-time monitoring of engine and .NET runtime metrics.

## Full Description

GodotPulse is a professional-grade performance monitoring and diagnostics plugin for Godot 4 .NET projects. It provides an in-game, toggleable overlay that displays real-time performance metrics with zero startup overhead when disabled.

### Key Features

**Performance Monitoring**
- Real-time FPS and frame time tracking
- Engine metrics: draw calls, VRAM usage, physics bodies, node counts
- .NET runtime metrics: managed heap size, garbage collection statistics
- GC spike visualization on performance graphs

**Developer Experience**
- Press F3 to toggle overlay (customizable)
- Multiple metric panels for organized data display
- Custom metrics API for tracking user-defined values
- Event logging for performance events
- Dark theme with professional styling

**Production Ready**
- Automatically disabled in release builds (configurable)
- Zero overhead when disabled
- Export-safe for Windows, Linux, and mobile platforms
- Full C# and GDScript integration support

### Requirements

- Godot 4.2+
- .NET 8.0+
- Godot built with .NET support enabled

### Installation

1. Download and extract to your project's `addons/` folder
2. Enable in Project Settings → Plugins
3. Autoload registers automatically
4. Press F3 during gameplay to toggle
